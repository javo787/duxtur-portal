# Автоблог: статья каждые 3 дня

Раз в 3 дня на сайте появляется новая медицинская статья на пяти языках (ru, uz, tg, kk, ky). Всё бесплатно: GitHub Actions + бесплатный тариф Gemini + открытые источники.

## Как это работает

```
GitHub Actions (каждый день 03:17 UTC)
  └─ scripts/auto-blog.ts
       1. GET  /api/cron/auto-blog     «пора ли? какая тема?»   (прошло ≥ 70 ч с прошлой статьи, тема по ротации рубрик)
       2. MedlinePlus (NLM) + Europe PMC (open access) → материал
       3. Gemini: черновик на русском строго по источникам → проверка фактов → перевод на uz, tg, kk, ky
       4. POST /api/cron/auto-blog     сайт ещё раз валидирует и публикует
            └─ revalidate списков, IndexNow, сообщение админу в Telegram
```

Cron срабатывает каждый день, а «раз в 3 дня» обеспечивает сайт: до истечения 70 часов он отвечает «рано». Если запуск упал, завтрашний запуск повторит попытку сам.

Код: `src/lib/auto-blog/` (логика), `src/app/api/cron/auto-blog/route.ts` (эндпоинт), `scripts/auto-blog.ts` (раннер), `.github/workflows/auto-blog.yml` (расписание).

## Подключение (один раз)

1. **Vercel → Environment Variables:** должен быть `CRON_SECRET` (длинная случайная строка; он уже нужен для `/api/cron/indexnow`). Если нет, создайте и сделайте redeploy.
2. **GitHub → репозиторий → Settings → Secrets and variables → Actions → Secrets:**
   - `CRON_SECRET`: то же значение, что в Vercel;
   - `GOOGLE_AI_KEY`: бесплатный ключ из https://aistudio.google.com/apikey.
   - Необязательные **Variables:** `SITE_URL` (по умолчанию `https://www.duxtur.org`, адрес должен быть конечным, без редиректа), `AUTO_BLOG_MODELS`.
3. **Проверка без публикации:** Actions → *Auto blog* → *Run workflow* (галочка `dry_run` включена). В логе будет тема и результат, готовая статья приложится файлом `auto-blog-dry-run`. Прочитайте её.
4. **Первая настоящая статья:** *Run workflow* с `dry_run` выключенным и `force` включённым. Дальше всё идёт само.

## Управление

| Что | Как |
|---|---|
| Поставить на паузу | `AUTO_BLOG_ENABLED=false` в Vercel (без деплоя кода) |
| Опубликовать вне очереди | Run workflow → `dry_run` off, `force` on |
| Добавить темы | `src/lib/auto-blog/topics.ts` (сейчас ~120 тем ≈ год; когда закончатся, запуск упадёт с понятным сообщением) |
| Сменить модель | переменная `AUTO_BLOG_MODELS="модель1,модель2"`: пробуются по порядку |
| Убрать статью | админ-панель. Внимание: тема освободится и может быть выбрана снова |

## Откуда берётся текст и почему не «перевод Healthline/Mayo»

Старый план (`AI_ARTICLE_PIPELINE_PLAN.md`) предлагал переводить статьи Healthline и Mayo Clinic со ссылкой на источник. Это не подходит: перевод чужой статьи остаётся копированием, ссылка права на публикацию не даёт. Поэтому факты берутся из **MedlinePlus** (Национальная медицинская библиотека США, общественное достояние) и **рефератов открытых обзоров Europe PMC**, а Gemini пишет **оригинальный** текст. Источники перечислены внизу каждой статьи.

## Что нужно знать

- **Статьи не проверяет врач.** На странице стоит пометка «подготовлено с помощью ИИ, пока не проверено врачом», `isVerified=false`, в Telegram приходит уведомление, а в админ-панели статья лежит среди непроверенных. Рекомендуется, чтобы врач просматривал каждую в течение 1–2 дней и ставил отметку.
- **Проверка фактов моделью — страховка, а не гарантия:** это та же модель, что проверяет свой текст. Дополнительно валидатор не пропускает дозировки лекарств, ссылки, HTML и неверную письменность (арабицу в таджикском, кириллицу в узбекском, русский текст под видом казахского).
- **Бесплатный тариф Gemini:** Google может использовать содержимое запросов для улучшения своих продуктов. Для публичных статей по открытым источникам это приемлемо; не отправляйте туда ничего приватного.
- **Модели Gemini устаревают.** `gemini-2.5-flash` отключён 16.10.2026. Новые дефолты: `gemini-3.8-flash` → `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite`; при недоступности одной пробуется следующая.
- GitHub отключает расписание в репозитории без активности 60 дней, это письмо придёт на почту владельца.
